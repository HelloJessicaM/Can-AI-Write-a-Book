# Can AI Write a Book? — Longform LLM Benchmark Corpus & Analysis Tools

This repository contains the raw generated manuscripts, custom diagnostic scripts, experiment matrix, and public control prompts for the **"Can AI Write a Book?"** benchmarking series by Jessica K. Murray.

📖 **Read the full pillar write-up:** [Can AI Write a Book? Measuring Local Models on 3 Old Computers]([https://jessicakmurray.com/can-ai-write-a-book/](https://jessicakmurray.com/can-ai-write-a-book/))

---

## 📌 About the Experiment

Can local, open-weights LLMs write a coherent 90,000-word novel on consumer hardware? What is the actual minimum cost floor, and how much "AI slop" (repetition and phrase recycling) comes out of unedited runs?

This ongoing experiment tests multiple model architectures (Dense vs. MoE) across three distinct hardware nodes using **BookyAI** as a fixed longform wrapper and **Ollama** as the backend:

| Node Name | GPU (VRAM) | System RAM | CPU | Memory Architecture |
| :--- | :--- | :--- | :--- | :--- |
| **boo-4070** | RTX 4070 (12GB) | 128GB | i9-14900KF | Dual-channel |
| **trex-3070** | RTX 3070 (8GB) | 64GB | i9-10980XE | Quad-channel |
| **backoffice-2060** | RTX 2060 (6GB) | 64GB | i7-1165G7 | Dual-channel |

> ⚠️ **Status: Active Benchmark.** Raw output folders and `matrix.csv` entries are committed as runs complete across all three test nodes.

---

## 📁 Repository Structure

* `prompt.md`: The verbatim public control prompt, genre parameters, and chapter pipeline used for every run.
* `matrix.csv`: The complete benchmark matrix tracking wall-clock time, tok/sec, target adherence %, repetition rates, memory footprints, and power consumption.
* `bookdiff.py`: Custom Python script to analyze overlapping 10-word text windows and measure internal repetition rates.
* `chaptertimes.ps1`: PowerShell script to compute generation times per chapter from file output timestamps.
* `/runs/`: Raw, unedited Markdown outputs generated by BookyAI, organized by `run_id`.

## 🛠️ How to Run the Analysis Scripts

### Internal Repetition Rate (`bookdiff.py`)
Requires Python 3.x. Evaluates overlapping 10-word n-gram windows to detect phrase loops and structural repetition:

```bash
# Analyze full file (including back matter)
python bookdiff.py repetition "runs/A3b_boo-4070_qwen3-8b_thinking-OFF/4070 - The Affirmation Glitch - qwen3:8b - NO thinking.md"

# Analyze novel body only (stops at back-matter headings)
python bookdiff.py repetition "runs/A3b_boo-4070_qwen3-8b_thinking-OFF/4070 - The Affirmation Glitch - qwen3:8b - NO thinking.md" --chapters-only
